# Nostalgia Assets Repository

Images used are not original and are taken from the below open source locations:

| Catalog | Source |
| ------- | ------ |
| Pokemon | [LazoVelko/Pokemon-Terminal](https://github.com/LazoVelko/Pokemon-Terminal) |
| Pride (Microsoft) | [Microsoft/Pride](https://github.com/microsoft/Pride/tree/main) |

## Releases

Pushing a tag that points to a commit on `main` creates a GitHub Release with a
`nostalgia-asstes-<tag>.zip` archive containing the `pokemon` and `pride` folders.
